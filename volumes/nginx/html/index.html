Spectre Server Layer

This page is a static file served by nginx from volumes/nginx/html/index.html. Every endpoint below is proxied by nginx to the Node.js application.

Endpoints

/health
Application liveness. Answers if the process is up; does not check dependencies.
/ready
Readiness. Checks PostgreSQL and Redis reachability and returns 503 when either is down.
/api/info
Reports the observed reachability of PostgreSQL and Redis, not just their configuration.
/api/data
Sample payload cached in Redis. Repeat the request within CACHE_TTL_SECONDS and cached flips to true.
/healthz
nginx's own liveness probe. Not proxied to the application.
TLS uses a self-signed development certificate. This stack serves HTTP on port 8081 and HTTPS on 8443, and your browser will warn about the certificate until you trust it. Replace it with a real certificate before exposing this anywhere.
Services: nginx · app (Node.js) · PostgreSQL · Redis. Ollama is available behind the optional ai Compose profile.
